\chapter*{\hfill{\centering  ЗАКЛЮЧЕНИЕ}\hfill}
\addcontentsline{toc}{chapter}{ЗАКЛЮЧЕНИЕ}

Цель работы, заключавшаяся в реализации программы для сжатия произвольных документов с использованием алгоритма Хаффмана, была достигнута.

Для достижения поставленной цели были решены следующие задачи:
\begin{enumerate}
	\item описан алгоритм сжатия информации с использованием алгоритма Хаффмана;
	\item определены средства программной реализации;
	\item реализована программа с использованием алгоритма Хаффмана;
	\item протестирована реализованная программа.
\end{enumerate}
