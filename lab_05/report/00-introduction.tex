\chapter*{ВВЕДЕНИЕ}
\addcontentsline{toc}{chapter}{ВВЕДЕНИЕ}

Целью лабораторной работы является реализация программы для сжатия произвольных документов с использованием алгоритма Хаффмана.

Для достижения поставленной цели необходимо решить следующие задачи:
\begin{enumerate}
	\item описать алгоритм сжатия информации с использованием алгоритма Хаффмана;
	\item определить средства программной реализации;
	\item реализовать программу с использованием алгоритма Хаффмана;
	\item протестировать реализованную программу.
\end{enumerate}
